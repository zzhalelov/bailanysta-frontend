# 🌐 Bailanysta — Социальная сеть

**Bailanysta** — это современная, минималистичная платформа социальной сети, позволяющая пользователям публиковать посты, просматривать ленту, ставить лайки, оставлять комментарии и генерировать контент с использованием ИИ.

---

### 🚀 Технический стек и обоснование выбора

- **Backend:** Java 17 + Spring Boot 3
  - *Почему:* Высокая надежность, отличный REST API фреймворк и удобство интеграции сторонних сервисов.
- **Frontend:** React + TypeScript + Vite
  - *Почему:* Высокая скорость сборки (Vite), типизация (TypeScript) и гибкость в создании чистого UI.
- **Database:** H2 Database / PostgreSQL
  - *Почему:* Легкость конфигурации, надежность и мгновенный запуск.
- **AI Integration:** Google Gemini API
  - *Почему:* Продвинутая генерация текста. Все вызовы осуществляются строго через backend-сервис для защиты API-ключей.

---

### 🔥 Ключевые возможности

1. **Лента постов и Профиль:** Разделение на главную ленту и личную страницу пользователя.
2. **AI Content Generator:** Автоматическая генерация постов через Gemini AI по заданной теме.
3. **Интерактивность:** Лайки, комментарии в реальном времени, поиск по автору и содержимому.
4. **UX / UI:** Поддержка Темной и Светлой темы (с сохранением выбора в `localStorage`), скелетоны загрузки (Skeleton Loaders).
